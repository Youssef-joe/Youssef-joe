### Building

- **[SoldierDB](https://youssef-joe.github.io/SoldierDB/)**: a relational database from scratch: crash-safe pages, copy-on-write B+tree, transactions, SQL and vector search. Go, with Rust and C++ clients.
- **[bricowerx](https://www.npmjs.com/package/bricowerx)**: feature memory for AI coding agents (CLI and MCP server), from the company I co-founded.
- **[OS](https://github.com/Youssef-joe/OS)**: small kernels for RISC-V and x86: SV32 paging, user mode, syscalls, interrupts and scheduling. C, C++, Assembly.
- **[lumina](https://github.com/Youssef-joe/lumina)**: formal verification toolchain that generates Coq proof obligations from Hoare logic. Rust.
- **[Ayno](https://github.com/Youssef-joe/Ayno)**: open-source Pusher alternative in Elixir.
- **[TADHKIRAH](https://github.com/Youssef-joe/TADHKIRAH)**: Arabic-first self-accountability app. NestJS, Next.js, PostgreSQL.
